A modern, AI-powered Admin Dashboard for the HaberBot platform.

**DESIGN SYSTEM (REQUIRED):**
- **Theme:** Dark mode exclusively. Background should be deep `#0A0A0F`.
- **Style:** Glassmorphic cards with thin borders (`1px solid rgba(255,255,255,0.1)`) and blurred backgrounds.
- **Typography:** Modern sans-serif (Inter/Outfit).
- **Colors:** Use a gradient of Purple (`#8B5CF6`) and Blue (`#3B82F6`) for primary buttons and AI highlights.
- **Shapes:** Soft rounded corners for all containers (`16px` or `24px`). Pill-shaped buttons.

**Page Structure:**
1. Sidebar or Top Navigation with Logo ("HaberBot Admin") and links (Topics, Settings).
2. Main Content Area containing a "Topics Management" section:
   - A glassmorphic table listing existing topics (Title, Slug, Source).
   - "Add New Topic" button.
3. System Controls Section:
   - "Fetch News" and "Process AI" action buttons with AI gradient styling.
   - Status indicators or progress bars showing the last run time.
