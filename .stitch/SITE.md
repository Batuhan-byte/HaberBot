# HaberBot Site Vision

## 1. Project Overview
HaberBot is an AI-powered news curation platform tailored for Turkish-speaking tech enthusiasts. It aggregates tech news (e.g., HackerNews, RSS feeds), summarizes them using Google Gemini API into "bite-sized" Turkish insights.

## 2. Target Audience
- Turkish-speaking developers, tech enthusiasts, and IT professionals.

## 3. Brand Personality
- Modern, AI-driven, fast, reliable, premium.

## 4. Sitemap
- [ ] `index` (Topic Feed & Search)
- [ ] `admin` (Admin Dashboard)

## 5. Roadmap
- `admin`: Needs a dashboard to manage topics (CRUD) and trigger fetches.
- `index`: Needs a modern feed of news cards with glassmorphic design and a search bar.

## 6. Creative Freedom
- Add futuristic loading skeletons.
- Add micro-interactions for hovering over news cards.
